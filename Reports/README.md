# 06 – Final Report

This folder contains the complete documentation of the **Week 5 Cyber Security Internship – VAPT Tools Practical Learning** activity.

The final report documents the complete Vulnerability Assessment and Penetration Testing workflow performed in an authorized VirtualBox cybersecurity laboratory. It covers the lab environment, target configuration, methodology, tools used, commands executed, observations, security findings, screenshots, impact analysis, mitigation recommendations, challenges faced, learning outcomes, and conclusion.

The assessment demonstrates the practical use of three commonly used security testing tools:

- **Nmap** – Network reconnaissance, port scanning, service detection, and version identification.
- **Nikto** – Web server assessment and identification of common security configuration issues.
- **Burp Suite** – HTTP request interception and analysis.

The report uses evidence collected from the authorized Ubuntu Apache web server with IP address `192.168.56.101`.

### Target Environment

- Attacker: Kali Linux
- Target: Ubuntu Linux
- Web Server: Apache 2.4.66 (Ubuntu)
- Target IP: `192.168.56.101`
- Network: `192.168.56.0/24`
- Web Service: HTTP on port `80`

The assignment-provided `testphp.vulnweb.com` target was found to be unreachable from the available lab network. Therefore, the assessment was completed using the authorized local Ubuntu Apache server as a controlled alternative target.

The report accurately documents the tools, commands, observations, screenshots, and findings obtained during the practical without claiming any testing that was not actually performed.
